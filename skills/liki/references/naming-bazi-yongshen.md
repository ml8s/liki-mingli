# 起名用神计划

## 数据流

出生信息明确时，先取得八字用神裁决，再直接复用其中的五行角色计划：

```text
出生信息
  → 排盘
  → 用神裁决能力
  → 选定用神
  → 取字能力 / 起名校验能力
```

八字域负责用神裁决。起名域只消费已定或部分确定的裁决；不读取冲突、证据、规则和策略来源，也不重新裁决用神。

## 消费口径

八字结果为已定或部分确定，且已给出具体用神五行时，才能进入选字。用神、喜神、忌神互斥；工具返回的计划是唯一口径。

## 组合策略

| 字位 | 可用角色 | 说明 |
| --- | --- | --- |
| 第一字位 | 用神或喜神 | 单名时只用这一位 |
| 第二字位 | 用神或喜神 | 省略表示单名 |

默认：单名用用神；双名至少一个字位用用神。生成阶段不提供忌神字池。

若喜神有多个五行，取字能力会为每个喜神五行返回独立字池，便于语义、音韵与出处筛选。

## 起名校验能力

起名校验能力使用同一个用神计划，对名字每个字的实际五行逐一分类为：命中用神、命中喜神、命中忌神或不属于上述三类。校验不预设「用 + 用」或「用 + 喜」，只如实返回每个字的角色。例如：

```text
梓涵 → 梓=用神，涵=喜神
梓林 → 梓=用神，林=用神
梓鑫 → 梓=用神，鑫=忌神
```

结构合法性与五行角色分开报告；五行角色不改变结构合法性。

## 输出

```text
八字依据：用神裁决结果
选字策略：第一字位 + 第二字位
逐字事实：汉字、五行、五行角色
```

不输出分数、排名、置信度或目标命中汇总。
