# 十神组合解读

## 消费规则

1. 先读扶抑、用神和十神相关断语；不得用通用十神知识另立结论。
2. 性格主面以月令十神类断语为准；其他十神断语只作辅面，不得反超主面。
3. 同一十神在不同身强弱、制化、组合下含义不同；必须以返回断语的条件和结论为准。
4. 命中「制化」「病处」「官杀取清」类断语时，该修正断语优先于普通吉象或十神表象。
5. 多条断语同向才可增强判断；冲突断语并列说明，不强行合并。

## 解读顺序

```text
1. 读扶抑 / 用神结果，确定身强弱与喜忌。
2. 读十神组合断语，列出事业、婚姻、性格相关候选。
3. 读制化与病处断语，标记优先修正。
4. 以月令主面组织性格；以相关领域断语组织事业、婚姻或财运结论。
5. 每条结论附断语 ID；无断语支撑的部分只作事实描述，不作命理定论。
```

## 边界

- 不用单一十神定论。
- 不把「杀印相生」「伤官配印」等组合名当作结论；必须落到返回断语的具体应事。
- 女命官杀混杂只消费婚姻相关断语；不自行推导婚变次数。
- 通用十神含义只能用于解释已返回断语，不能用来新增断语。
