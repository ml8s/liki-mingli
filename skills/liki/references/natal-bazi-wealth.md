# 财运解读

## 消费规则

1. 财运结论必须来自财运相关断语；不得用通用“财星”“比劫”知识另立结论。
2. 按返回断语区分三类证据：财源、竞争 / 破耗、根基 / 储蓄。
3. 身强弱与喜忌已由扶抑 / 用神结果给出；只用于解释断语，不重新推导。
4. 同向断语可增强判断；冲突断语并列说明，不强行合并。

## 解读顺序

```text
1. 读财源类断语：是否有稳定收入、技艺生财、食伤生财或财库蓄财。
2. 读竞争 / 破耗类断语：比劫争财、驿马破财、财坏印、忌神攻财等。
3. 读大运 / 流年引动类断语：财务变动、得财候选、破财候选。
4. 结合双侧断语给出层次、风险与时间窗口。
5. 每条结论附断语 ID；无断语支撑时只描述事实，不作财运定论。
```

## 边界

- 不把“比劫争财”直接断为破财；须以返回断语的条件为准。
- 不用单一财星判断贫富；须合参财源、身强弱、竞争和根基证据。
- 断语未覆盖的具体投资、借贷决策，只提示现实风险，不给出财务建议。
